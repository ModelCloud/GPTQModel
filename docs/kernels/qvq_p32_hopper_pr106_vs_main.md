# PR #106 versus origin/main on physical H100

This report compares PR commit `ab7b8252` with `origin/main` commit `78d699cc` on the same physical NVIDIA H100 (SM90, 132 SMs). Both runs used warmed CUDA Graph replay timed only with CUDA events. QKV used 10 warmups, 15 samples, and 3 replays/sample. The much slower main MLP used 5 warmups, 9 samples, and 1 replay/sample; the PR used the identical MLP schedule. The benchmark-only M ladder extension changes no kernel/runtime source. W4 Marlin/Machete are figurative execution baselines because QVQ uses W2-W3.5.

At QKV M8192, the PR uses the default source-versioned folded-FP8 cache. At M16384, `QVQ_HOPPER_FP8_PREFILL_ON_DEMAND=1` selects bounded per-forward FP8 preparation with only 8 logical retained bytes. Other QKV rows use exact grouped P32. The MLP table is the full gate/up -> SiLU/product -> down operation.
