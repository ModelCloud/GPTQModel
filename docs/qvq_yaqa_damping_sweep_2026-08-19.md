# QVQ YAQA damping sweep — 2026-08-19

## Decision

The completed full-depth sweep supports the following default policy:

| Rate range | Default YAQA damping |
|---|---:|
| W1 through W4 | 0.10 |
| Above W4 | 0.05 |

The policy applies to the factor diagonal damping used by YAQA. Explicit
`regularization` and exact-rate `regularization_by_rate` settings continue to
override these defaults. The paper-faithful value `1e-4` remains available
explicitly for reproducing paper/reference experiments.

## Sweep configuration

- Model: Llama 3.2 1B
- Scope: all 16 decoder layers and all 112 linear modules
- Arm: `v2-yaqa`
- Rates: W1, W1.5, W2, W2.5, W3, W3.5, W4
- Damping values: default, 0.001, 0.003, 0.005, 0.01, 0.02, 0.05, 0.10
- Calibration: 512 rows
- Evaluation: disjoint rows 512–1023
- YAQA: disjoint rows 1024–1535, batch size 8
- Batch/concat: batch size 1, no concatenation
- Output alignment: disabled

## Interpretation

`0.10` produced the lowest final KL at every tested rate and the strongest or
near-strongest Top-N agreement. W3 Top-5 and W4 Top-1 had tiny single-metric
advantages at lower damping, but not enough to change the default policy.
Runtime differences were within normal sweep noise; this change affects YAQA
factor stabilization and selection, not the codec payload or inference kernel.
